There is real value in pointing a model at the volume of text that compliance work generates.
There is no value in an answer nobody can defend six months later in an audit.

The workable shape so far is narrow: the model summarises, classifies and drafts; the control
logic, the thresholds and the final determination stay deterministic and logged. Trial rather
than adopt, because the failure modes are still being learned.
